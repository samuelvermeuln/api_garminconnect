# Garmin API Routes

Base local URL used in examples:

```text
http://localhost:8001
```

## Authentication

Headers used by the API:

- `X-Admin-Key` — required for `POST /accounts` when `GARMIN_API_ADMIN_KEY` is configured.
- `X-API-Key` — required for account-scoped routes.

## Common response shapes

### Data routes

Most Garmin data routes return:

```json
{
  "account_id": "internal-account-id",
  "data": {},
  "cached": false
}
```

- `account_id`: internal account identifier generated by this API.
- `data`: raw Garmin payload for that route.
- `cached`: `true` when served from short in-memory cache.

### Daily report

`GET /daily-report/{date}` returns:

```json
{
  "account_id": "internal-account-id",
  "date": "2026-05-26",
  "cached": false,
  "summary": {},
  "health": {},
  "training": {},
  "body": {},
  "nutrition": {},
  "warnings": []
}
```

### Account creation

`POST /accounts` returns:

```json
{
  "account_id": "internal-account-id",
  "api_key": "secret-account-api-key",
  "mfa_required": false,
  "message": "GARMIN_CONNECTED"
}
```

## Routes

## System

### `GET /health`
- Auth: none
- Returns: `{"status": "ok"}`

### `GET /docs`
- Auth: none
- Returns: Scalar interactive API documentation HTML.

### `GET /openapi.json`
- Auth: none
- Returns: generated OpenAPI schema.

## Accounts

### `POST /accounts`
- Auth: `X-Admin-Key` when admin key is configured
- Body:
  - `email`
  - `password`
  - `label` (optional)
  - `is_cn` (optional)
- Returns:
  - `account_id`
  - `api_key`
  - `mfa_required`
  - `message`

### `POST /accounts/mfa`
- Auth: `X-API-Key`
- Body:
  - `mfa_code`
- Returns:

```json
{
  "status": "ok",
  "message": "MFA completed"
}
```

### `GET /me`
- Auth: `X-API-Key`
- Returns:

```json
{
  "account_id": "internal-account-id",
  "label": "optional-label",
  "authenticated": true
}
```

### `GET /devices`
- Auth: `X-API-Key`
- Returns: Garmin device list for the account inside standard data wrapper.

## Daily report

### `GET /daily-report/{date}`
- Auth: `X-API-Key`
- Returns aggregated report with:
  - `summary`
  - `health`
  - `training`

- Auth: `X-API-Key`
- Returns: Garmin Connect+ nutrition settings payload inside standard data wrapper.

### `POST /nutrition/food-photo/analyze`
- Auth: `X-API-Key`
- Body: multipart form data
  - `photo` (`image/*`)
  - `meal_type` (optional)
  - `notes` (optional)
- Current behavior: validates upload and returns placeholder response with HTTP `501`.
- Returns:

```json
{
  "account_id": "internal-account-id",
  "status": "unsupported",
  "message": "Garmin Connect+ supports photo-based food logging in the app, but this private wrapper has no mapped Garmin upload endpoint yet.",
  "garmin_connect_plus_feature": true,
  "filename": "meal.jpg",
  "content_type": "image/jpeg",
  "meal_type": "lunch",
  "notes": "rice, chicken and salad",
  "next_steps": []
}
```

## Error patterns

Common status codes:

- `400` — invalid input or validation error.
- `401` — invalid `X-Admin-Key` or `X-API-Key`.
- `429` — Garmin rate limit reached.
- `502` — Garmin communication/login failure.
